# Hansika Gupta — Portfolio

A static site with no build step: `index.html`, `styles.css`, `main.js`, `favicon.svg`.

## Preview locally
Double-click `index.html`, or run `npx serve .` inside this folder.

## Deploy on Vercel
**Option A, drag and drop:** go to vercel.com/new and import this folder (or upload it after pushing to GitHub).
Framework preset: **Other**. Leave the build command and output directory empty.

**Option B, CLI:**
```
npm i -g vercel
cd portfolio
vercel        # preview deploy
vercel --prod # production deploy
```

## Links
All project "Code" buttons, LinkedIn and GitHub links are set in `index.html`.
